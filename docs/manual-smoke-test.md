# V0.1 Manual Smoke Test

- [ ] New Game: each school type and ownership option can be selected.
- [ ] Curriculum: missing/invalid curriculum is blocked with readable feedback.
- [ ] Campus: 40×30 map renders on first load.
- [ ] Build: floor/wall/door/preset placement works and out-of-bounds clicks do not crash.
- [ ] Rooms: incomplete classroom displays missing requirements; completed classroom becomes functional.
- [ ] People: day and boarding students can be admitted; staff can be hired.
- [ ] Timetable: overlapping periods are rejected; valid edits persist in memory.
- [ ] NPCs: autonomous students/staff receive schedule destinations and route around walls.
- [ ] Zones: students cannot cross staff-only/restricted areas without access.
- [ ] Life Sim: active student can move with WASD/arrows and click-to-move.
- [ ] Interaction: E/right-click actions work only when appropriate.
- [ ] Needs: energy/hunger/stress/mood update and stay within 0..100.
- [ ] Finance: daily income/expenses post once per day.
- [ ] Save/Load: save survives full browser refresh.
- [ ] Character JSON: valid export re-imports; malformed/unsupported file is rejected safely.
- [ ] GitHub Pages: game loads from a repository subpath with no absolute-path 404s.
- [ ] Console: no uncaught exceptions during a ten-minute play session.
